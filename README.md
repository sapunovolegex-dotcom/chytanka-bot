# Бот каналу «Читанка на зв'язку»

Бот запускається на GitHub Actions кожні 5 хвилин, окремий сервер не потрібен.

Що він робить:

- **Новини з сайтів.** Бере свіжі новини з RSS-стрічок і надсилає вам у приватні з кнопками «Опублікувати» / «Пропустити». Кнопка публікує заголовок із посиланням на джерело. Якщо відповісти (reply) на пропозицію своїм текстом, у канал піде ваш текст із посиланням.
- **Новини від людей.** Люди пишуть боту, ви отримуєте повідомлення з кнопками «У канал» / «Відхилити».
- **Пости за розкладом.** Файли з папки `posts/` публікуються у вказаний час (див. `posts/ПРИКЛАД.md`).
- **Чат.** Вітає нових учасників, показує правила за командою `/rules`, видаляє повідомлення з посиланнями від не-адмінів.

Бот реагує не миттєво, а під час наступного запуску: зазвичай за 5–15 хвилин.

## Налаштування

### 1. Створіть бота
1. У Telegram відкрийте **@BotFather** → `/newbot`.
2. Дайте ім'я (наприклад, «Читанка на зв'язку») і юзернейм, що закінчується на `bot`.
3. Збережіть **токен**. Нікому його не показуйте й не вставляйте у файли.

### 2. Додайте бота в канал і чат
- **Канал:** Керування каналом → Адміністратори → додайте бота з правом «Публікація повідомлень».
- **Чат:** додайте бота адміністратором із правом «Видалення повідомлень».

### 3. Дізнайтеся свої ID
- **ADMIN_ID** — ваш числовий ID: напишіть боту **@userinfobot**.
- **CHANNEL_ID** — юзернейм каналу з @, наприклад `@chytanka_na_zvyazku`.
- **GROUP_ID** — юзернейм чату з @, якщо чат публічний. Якщо приватний, потрібен числовий ID, що починається з `-100`.

Потім обов'язково напишіть своєму боту `/start`, інакше він не зможе вам писати.

### 4. Завантажте код на GitHub
1. Створіть на github.com новий **публічний** репозиторій (для публічних Actions безкоштовні без ліміту; у приватному запуск кожні 5 хвилин вичерпає безкоштовні хвилини).
2. Завантажте всі файли з цієї папки, разом із `.github/workflows/bot.yml`.

### 5. Додайте секрети
Репозиторій → **Settings → Secrets and variables → Actions → New repository secret**. Створіть чотири:

| Назва | Значення |
|---|---|
| `BOT_TOKEN` | токен від BotFather |
| `ADMIN_ID` | ваш числовий ID |
| `CHANNEL_ID` | `@юзернейм_каналу` |
| `GROUP_ID` | `@юзернейм_чату` (можна не створювати, тоді бот не модеруватиме чат) |

### 6. Запустіть
Вкладка **Actions** → «Chytanka bot» → **Run workflow**. Далі бот запускатиметься сам.

Під час першого запуску бот лише запам'ятовує вже наявні новини на сайтах і нічого не пропонує. Пропозиції почнуться з наступних свіжих новин.

## Налаштування в `config.json`

- `feeds` — список сайтів. Щоб додати сайт, впишіть його назву й адресу RSS. Якщо сайт не лише про Чернігівщину, поставте `"filter": true`: тоді бот братиме тільки новини зі словами зі списку `keywords`.
- `max_proposals_per_run` — скільки новин пропонувати за один запуск.
- `delete_links` — чи видаляти посилання від не-адмінів у чаті.
- `start_text`, `thanks_text`, `welcome_text`, `rules_text` — тексти бота.

## Про чужі новини

Не копіюйте тексти статей цілком: це порушує авторські права, і канал можуть заблокувати. Публікуйте заголовок або короткий переказ своїми словами з посиланням на джерело. Саме так бот і робить.
